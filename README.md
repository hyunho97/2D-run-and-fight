# 블록 체인 RPG — 프로토타입

## ▶ 플레이: https://hyunho97.github.io/2D-run-and-fight/

설치 없이 링크만 열면 PC·모바일 브라우저에서 바로 플레이할 수 있습니다. 진행 상황은 각자의 브라우저(localStorage)에 저장됩니다.

HTML5 Canvas + 순수 JavaScript, 빌드/서버 불필요. (기획서는 비공개)

## 현재 구현 범위

| 영역 | 내용 |
|---|---|
| 전투 | 블록 바 9칸(리더 가중치 2배), 1·2·3체인, 자동 전진, 웨이브 3 + 보스(2페이즈·시전), 2분 광폭화, 별 평가, 자동/배속/일시정지 |
| 진행 | 챕터 1 숲 10스테이지(순차 해금), 승리 보상(골드·EXP·첫 클리어 보석·★1 유닛 드롭) |
| 유닛 | 기본 유닛 576종(6직업 × 6등급 × 16색), 레벨업(최대 = 등급×10), 첫 MAX 레벨 보상 |
| 성장 | 합성(★N MAX ×2 → 랜덤 ★N+1, ★4+ 결과 메인 5%, 한정 경고), 강화 +1~+5, 진화(메인 전용) |
| 획득 | 보석 소환(★1 80% / ★2 20%) |
| 화면 | 로비, 스테이지 선택, 파티 편성(배치·리더), 보관함(등급 필터), 유닛 상세, 도움말 |

### 진행 곡선 (자동 플레이 시뮬레이션 기준)

| 파티 성장도 | 클리어 가능 |
|---|---|
| ★1 Lv.1 | 1-5까지 |
| ★1 MAX | 1-7까지 |
| ★2 | 1-9까지 |
| ★2 MAX / ★3 | 1-10 |

## 다음 단계 (기획 확정 필요)

1. **메인 캐릭터** — 이미지·컨셉·전용 스킬 확정 후 추가 (데이터 형식·합성 5%·진화 로직은 준비됨)
2. **지원 스킬 게이지 / 와일드 블록** — 충전 조건·수치 확정 필요
3. **장비** (무기/방어구/장신구), 스킬 강화
4. **챕터 2(사막)** 이후 스테이지, 게임 모드(무한의 탑·일일 던전 등)
5. **아트/사운드** — 현재 도형 플레이스홀더

## 배포

GitHub Pages(`main` 브랜치 루트)로 정적 배포됩니다. `main`에 push하면 1~2분 후 위 링크에 자동 반영됩니다.

## 로컬 실행

- `index.html`을 브라우저로 열기 (더블클릭)
- 테스트: `npm test`
- 밸런스 시뮬레이션: `npm run sim -- 40 BAS_0001,BAS_0003,BAS_0004 0 stage=all grade=1 level=10`
  (`[판수] [파티] [리더] [stage=ID|all] [grade=N] [level=N] [CONFIG_KEY=값 ...]`)

### 디버그 URL 파라미터

아래 파라미터가 있으면 세이브와 무관한 단독 전투로 바로 시작합니다 (진행 미반영).

| 파라미터 | 예 | 설명 |
|---|---|---|
| `stage` | `STG_01_10` | 스테이지 |
| `party` | `BAS_0001,BAS_0004,BAS_0005` | 전열→후열 순서 3명 |
| `leader` | `0` | 리더 인덱스 |
| `seed` | `123` | 난수 시드 고정 |
| `warp` | `110` | N초 미리 진행 (보스·광폭화 확인용) |

## 조작

| 입력 | 동작 |
|---|---|
| 블록 탭 / 숫자키 1~9 | 해당 칸이 속한 체인 스킬 발동 |
| 블록 길게 누르기 | 스킬 정보 툴팁 |
| x1/x2 버튼, `S` | 배속 |
| AUTO 버튼, `A` | 자동 블록 사용 |
| ⏸ 버튼, `Space` / `Esc` | 일시정지 (계속 / 다시 / 나가기) |

## 구조 (기획서 12.2 / 12.3 대응)

```
src/
  core.js, config.js, rules.js     공용 유틸 / 밸런스 상수(TBD 표시) / 성장 공식
  data.js                          직업, 기본 유닛 카탈로그, 적, 챕터 1 스테이지
  battle/
    BattleManager.js               전투 상태 머신, 웨이브, 광폭화, 승패·별 평가, 자동 모드
    BlockManager.js                블록 생성(리더 가중치 2배, 사망자 제외), 소모
    ChainResolver.js               인접 블록 체인 판정 (최대 3)
    SkillExecutor.js               체인 레벨별 스킬 실행
    DamageCalculator.js            데미지 공식, 속성 상성
    StatusEffectSystem.js          상태이상 (CC/화상/방깎/보호막/지속치유)
    Unit.js                        유닛 스탯 (등급·레벨·강화 배율)
  meta/
    Progression.js                 보상, 레벨업, 합성, 강화, 진화, 소환, 세이브 검증
    SaveManager.js                 localStorage 저장/불러오기
  ui/
    Renderer.js                    전투 Canvas 렌더링 / 연출
    Screens.js, style.css          메뉴 화면 (DOM)
  main.js                          화면 전환, 게임 루프, 입력
tests/run-tests.js                 Node 단위 테스트
tools/simulate.js                  헤드리스 밸런스 시뮬레이터
```

`battle/`, `meta/`는 DOM에 의존하지 않아 Node에서 그대로 실행됩니다.
